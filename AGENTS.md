# Project Rules — Vktor Data

## Objective
This is not a portfolio. It is a lead generation and service sales system.

## Priorities
1. Clarity
2. Conversion
3. Credibility
4. Simplicity

## Design Principles
- Minimal, premium (dark + gold)
- No visual clutter
- Strong hierarchy
- Scannable sections

## Content Rules
- Avoid long paragraphs
- Always show proof (projects, experience, stack)
- Every section must have a purpose

## Technical Rules
- Use reusable components
- Keep components small and composable
- Use data-driven structures where possible

## Conversion Rules
- Every page must have CTA
- Balance persuasion with credibility
- Avoid over-aggressive messaging without proof

## Anti-patterns
- No generic portfolio sections
- No empty claims without evidence
- No large text blocks
